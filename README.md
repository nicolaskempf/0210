# HelpDesk TI - Projeto Integrado P1

Projeto da disciplina **Desenvolvimento de Interfaces de Usuário para Web**.

## Integrante

- **Nicolas Alexandr Kempf**

## Descrição

Interface simples de um sistema de chamados de suporte de TI, com visualização de chamados, detalhes e cadastro de novo chamado.

## Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS

## Telas

- Login
- Início / Dashboard
- Chamados
- Novo chamado
- Detalhes do chamado

## Como executar

```bash
npm install
npm run dev
```

Para testar a produção:

```bash
npm run build
```

Nesta etapa foram usados dados simulados. API REST, banco e CRUD completo ficam para etapas posteriores.
